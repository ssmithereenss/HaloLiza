# 🎂 Website Ucapan Ulang Tahun untuk Liza

Website statis (HTML + CSS + JavaScript) berisi ucapan ulang tahun dengan animasi GSAP, musik, dan halaman login sederhana.


## Cara pakai

1. Buka folder ini dengan Live Server (VS Code), atau klik dua kali `index.html`.
2. Login dengan username dan password di `scripts/index.js` (bagian `LOGIN`, default: `liza` / `liza`).
3. Deploy: drag & drop folder ke [Netlify](https://www.netlify.com/).

## Yang bisa diubah

| Apa | Di mana |
| --- | --- |
| Username & password | `scripts/index.js` (objek `LOGIN`) |
| Isi ucapan | `birthday.html` |
| Foto | ganti `img/liza.jpg` (disarankan persegi) |
| Musik | ganti `music/hbd.mp3` |
| Urutan & durasi animasi | `scripts/birthday.js` |

> Catatan: login hanya penghias supaya terasa seperti kejutan. Isinya tidak benar-benar rahasia.
